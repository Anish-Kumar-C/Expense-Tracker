# 💸 CLI Expense Tracker

A simple, no-nonsense command-line expense tracker that helps you manage your spending. Built with pure Python—no external dependencies required.

![Python Version](https://img.shields.io/badge/python-3.7+-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

---

## ✨ Features

- ➕ **Add expenses** with description, amount, and category
- 📋 **View all expenses** with timestamps
- 💰 **See totals by category** (Food, Transport, Shopping, Bills, Other)
- 🏦 **Grand total** displayed at a glance
- 💾 **Persistent storage** – your data auto-saves to a JSON file
- 📁 **No external packages** – runs with Python out of the box
